# Around The U.S.

![Around The U.S.](images/logo.svg)

## 📋 Sobre o Projeto:

Around The U.S. é uma página interativa de galeria de lugares turísticos, desenvolvida como parte do bootcamp de desenvolvimento web. O projeto permite aos usuários visualizar, adicionar e interagir com cartões de locais, além de editar seu perfil.

## 🚀 Funcionalidades

### 👤 Perfil do Usuário
- Editar nome e descrição do perfil
- Validação em tempo real dos campos (2-40 caracteres)
- Feedback visual com mensagens de erro personalizadas

### 🖼️ Galeria de Cartões
- Exibição dinâmica de cartões com imagens e títulos
- Adicionar novos cartões com título e URL da imagem
- Curtir cartões com efeito visual
- Excluir cartões com confirmação
- Visualizar imagens em tamanho ampliado

### ✅ Validações
- **Editar Perfil:** Nome (2-40 caracteres), Sobre (2-200 caracteres)
- **Novo Local:** Título (2-30 caracteres), URL válida
- Mensagens de erro claras e específicas
- Botão de submit desabilitado até formulário estar válido

### 🎨 Experiência do Usuário
- Pop-ups modais para ações principais
- Fechar modais clicando fora ou com a tecla ESC
- Design responsivo para todos os dispositivos
- Feedback visual em todas as interações

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização e responsividade
- **JavaScript (ES6+)** - Interatividade e manipulação do DOM
- **BEM (Block Element Modifier)** - Metodologia de nomenclatura CSS
